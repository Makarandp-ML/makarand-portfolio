## Run locally
This is a static site. To preview it locally, put the files in one folder and run:
```bash
python -m http.server 8000
```
Then open http://localhost:8000.

## Publish with GitHub Pages
The source files are placed at the repository root for GitHub Pages. In **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. GitHub will show the published URL when deployment is ready.
